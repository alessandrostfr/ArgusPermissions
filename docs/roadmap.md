# Roadmap

## Estado actual

ArgusPermissions queda como proyecto legacy documentado y presentable.

## Mejoras razonables

- Añadir tests de Feature para:
  - login;
  - creación de roles;
  - asignación de permisos;
  - autorización por Gate;
  - edición de usuario propio vs usuario ajeno.
- Añadir capturas al README.
- Limpiar ramas antiguas de Dependabot.
- Añadir descripción y topics en GitHub.
- Crear release `v0.1-legacy`.

## Mejoras grandes

- Migrar a Laravel moderno.
- Convertirlo en paquete Composer.
- Añadir Service Provider propio.
- Publicar configuración, migraciones y seeders.
- Añadir middleware reusable por permiso.
- Añadir documentación de instalación como paquete.
- Añadir tests automatizados reales.
